# 名前欄（場所名の帯）仕様

確定: 2026-11-13。地色は前記のとおり「カード全体のベース（aged v3）の紙の上に、一段濃い茶褐色を乗せる」（文字は生成り）。配置は同日に本人が追加決定: **「名前欄内の文字はセンター寄せ。そのうえでバランスよく名前欄に配置」**。

## 濃茶の塗り方（透過・2026-11-13 本人訂正）
- **名前欄は、透過性のある濃い茶色で塗る**。不透明なベタ塗りではない。
- **透過を持たせる目的は、紙の質感を感じさせるため**。下にある aged v3 の紙の質感（紙目・染み・経年のムラ・かすれ）が、濃茶を通してそのまま透けて見えることが条件。濃茶を重ねた部分でも、紙は「紙のまま色だけ沈んだ」状態になる。
- 人工的なノイズや汚しを濃茶の側に描き足して質感を偽装するのは不可（モカの初期見本がこの誤り。不透明な濃茶＋合成ノイズは本人の意図と違う）。
- **濃茶には、紙質・世界観・空気感に合わせた僅かな濃淡をつける**（2026-11-13 本人指示）。均一な一色の塗りは「濃い茶色の四角を載せた」状態になり不可。紙の染みや経年の流れに沿う、大きな柔らかい濃淡のうねり＋紙目の細かい揺らぎで、「その部分の紙そのものが濃い茶に染まった」状態にする。濃淡は僅かに（明暗のうねりは1割前後）。枠の線と隅飾りは濃茶の上に元のまま残る（枠が上の層）。
- 濃さの目安: 元の紙の明暗の差がはっきり読み取れる範囲で、一段濃い茶褐色まで沈める（合成の目安として、暗い茶色レイヤーの不透明度は約65〜75%。最終値は見本で本人が確認する）。
- 本番合成では、名前欄の下には紙だけがある状態（文字はまだ描かれていない）で透過の濃茶を重ねる。生成済み画像の上に重ねる見本では、元の黒文字が透けて残らないよう先に紙で消してから重ねる。

## 枠内の充填ルール（余白なし・2026-11-13 本人決定）
- **枠で囲まれた領域は、内側を余白なくぴったり埋める**。名前欄・イラストエリア共通の原則。
- 名前欄の濃茶は、囲んでいる枠線の内縁から内縁まで（上は上枠線の内側、下は下枠線の内側、右は右枠線の内側）隙間なく入れる。枠の内側に、濃茶ではない生成りの余白が残るのは不可。
- 同時に、**濃茶が枠線にかかるのも不可**。枠線は濃茶の上に完全な形で見える（レイヤー順の節と一体）。充填範囲は「枠線の内縁まで、線そのものは含まない」が正確な境界。
- イラストエリアも同じ: **絵を枠の内縁にぴったり合わせ、絵と枠の間に余白を残さない**。絵が枠線に被るのも不可（絵も枠の下の層）。
- 実測の目安（aged v3 カジノ・1280×1920）: 名前欄の充填範囲は、上の枠線（y=83〜86）の下縁 y=87 から、下の枠線（y=264〜266）の上縁 y=263 まで、右は右枠線（x=1171〜1175）の左縁 x=1170 まで。左は鉄板の右縁まで（鉄板の下になる部分は鉄板が上に載る）。

## カードの枠は真鍮細工（2026-11-13 本人決定）
- **枠（外枠の二重線・名前欄の仕切り線・イラスト枠の細線・四隅の隅飾り・イラスト枠の隅金具）は真鍮細工とする**。
- **形は維持する**: 線の位置・太さ・隅飾りの形状は aged v3 の現行のまま一切変えず、素材だけを真鍮に読み替える。
- 真鍮の質感は紋章と同基準の「使い込まれた真鍮」: サビ（緑青・腐食色）は入れない。元の線画・彫りの陰影をそのまま金属の陰影として使う（暗部は深いブロンズ、稜線のハイライトは明るい真鍮色）。

## レイヤー順と角の処理（枠との関係・2026-11-13 本人決定）
- **濃い茶色は枠より下に配置する**。レイヤー順は「ベースの紙 → 濃い茶色（名前欄）→ 枠（一番上）」。枠線と隅飾りは、常に濃茶の上に載る。
- **角の切り取り**: 枠が上に載ることにより、濃茶の角の形は、枠の内側のラインに沿って切り取られるように削れる。濃茶が枠線・隅飾りを覆ったり、角が四角いまま枠にはみ出したりすることはない。枠の角に丸みがある箇所では、濃茶の角もその内側の曲線に沿って落ちる。
- **枠の外側は余白**: 濃茶は枠の内側までで止まり、枠の外側（カードの縁までの余白部分）には一切出ない。外側はベースの紙（生成りの余白）のまま。
- つまり濃茶の描画範囲は、上下左右とも「枠の内側のラインで切り取られた内側」だけ。見本・本番合成とも、先に濃茶を置いてから枠を上に描く（または枠の内側形状で濃茶をクリッピングする）手順で作る。

## センターの定義（重要）
- センター寄せの基準は、カード幅全体でも、帯の全長（鉄板の裏を通る部分を含む）でもない。**鉄板に隠れていない「見えている名前欄」の中央**に、文字ブロックの中央を合わせる。
- 見えている名前欄の範囲（本番合成キャンバス 1000×1500 での値。1280×1920 では ×1.28）:
  - 帯そのもの: x=46〜954、y=76〜204（高さ128）。
  - 左端（可視の左）: 鉄板の右辺 x=348 に余白24を足した x=372。鉄板に文字が寄りかかった印象にしないための最小余白で、これより左へ文字を出さない。
  - 右端（可視の右）: 内枠の右端 x=954 から、右上の隅飾りと余白ぶん24を引いた x=930。
  - **横の中心 = (372+930) ÷ 2 = 651。縦の中心 = 帯の中央 y=140。**（縦横とも、中心は「枠の内縁で囲まれた充填範囲」の中央で取る。前節の充填ルールと一体）
- 縦方向もセンター: 文字の見た目の中心（文字の外接矩形の中心）＝帯の縦中心に合わせる。フォントの行ボックスやベースライン基準で置くと上に浮く／下に沈むため、外接矩形基準で合わせる。

## バランスの規則
- 左右の余白は必ず等しくする（センター寄せの結果として、文字ブロックの左右に残る余白が同量になる）。左寄せ・右寄せは不可。
- 文字サイズは全カード共通を原則とする（名前欄の高さの約55〜60%の字高）。2文字（裏口・顔役・本部・密書）だからといって拡大せず、5文字（場末の酒場・高級クラブ・高層タワー）だからといって左へ寄せない。長短の差はセンター配置が吸収し、全カードで字の大きさが揃うこと自体がバランスになる。
- 字間は均一に、わずかに広げる（字高の約6〜10%）。文字ごとに間隔が変わる詰め方はしない。
- 5文字でも可視幅（558）に収まり、左右それぞれ最低でも可視幅の約8%の余白が残るサイズに収める。収まらない場合は左寄せにせず、文字サイズを段階的に下げる（100%→92%→85%）。
- 横方向へ圧縮する変形（長体・平体）はかけない。
- 鉄板側の余白と隅飾り側の余白の見え方が揃うよう、右端は隅飾りの内側を基準にする（上記 x=930）。隅飾りに文字が近づいた印象にしない。
- 文字は生成りの単色、古典的なセリフ／明朝体、軽い印刷のかすれは全体の風合いに合わせるが、名前欄だけかすれを強くしない。
