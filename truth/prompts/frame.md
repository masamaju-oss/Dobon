# 枠の仕様（aged v2 を正規品とする）

2026-11-14、本人が「24カジノ aged v2 の絵の枠を正規品とする」と決定。
これにより枠の基準は aged v1 から aged v2 へ差し替わる（旧登録は履歴として台帳に残る）。
原本は作業場の aged v2 カード（1280×1920）。この文書は、その枠を再現できる粒度で言語化したもの。

## 枠の定義

枠 = 紙の上に描かれた罫線の体系＋四隅の唐草隅飾り。
枠ではないもの: 紙そのもの（紙質は aged v3 が正・R-407）、名前の文字、紋章シールド、
イラスト、鉄板、そしてカードの外縁（縁の擦れ・汚れは枠とは別の要素。2026-11-14 本人指摘）。
名前欄の「地」は v2 では無地の紙（色づけなし）。
※名前欄の地色（R-404 は v1 式の茶褐色の透過地）は、この決定で前提が変わるため再確認待ち。

## 罫線の幾何（実測、1280×1920 座標、単位 px）

- 外周の二重罫（カード全体を囲む矩形）:
  - 上: 外線の中心 y≈63（太さ約10）、内線の中心 y≈80（太さ約5）、間隔は紙が約7
  - 下: 外線の中心 y≈1857、内線の中心 y≈1842（内線は中央部が原画でも擦れて淡い。そのまま残す）
  - 左: 外線の中心 x≈63、内線の中心 x≈85
  - 右: 外線の中心 x≈1197、内線の中心 x≈1180
- 名前欄: 上の二重罫の下端（y≈88）から仕切り線まで（y≈266）。地は無地の紙。
- 名前欄の仕切り線（名前欄の下辺＝窓の上辺）: 二重で、中心 y≈275 と y≈286。
- 窓（イラストの範囲）: 左辺の線 x≈105、右辺の線 x≈1170、上辺 y≈289、下辺の線の中心 y≈1641。
  - 窓の下の隅には小さな L 字の飾り（隅から約25px の tick）が付く。
- 下の帯: 窓の下辺（y≈1650）から下の二重罫（y≈1834）まで。地は無地の紙。
- 罫線の色: 暗い茶 RGB おおよそ (60, 44, 24)。手描きの僅かなうねりと擦れがある（完全な直線ではない）。

## 隅飾り（四隅・唐草）

- 素材感: aged v1 の帯の飾りと同じ家系の、彫りのある真鍮色の唐草。ただし v1 の大きな隅飾りより
  一回り小さく、線画に近い軽さで、罫線の角に「乗る」ように描かれている（線の上に被さる）。
- 大きさ（実測・アルファの範囲）: 上の隅 約213×215（左上 x14〜227・y14〜229、右上はその鏡像位置）。
  下の隅は幅 約215、本体は y≈1655〜1850（上端の蔓が窓の下辺近くまで伸び、下端の流れが下の二重罫に被さる）。
- 形: 二重の渦巻き（ボリュート）を芯に、葉のうねりが縦・横の罫に沿って伸び、先端は小さな渦で完結する。
  四隅とも同デザインの反転・回転配置。

## カードの縁

- 原画の外周には使い込まれた暗い擦れがあるが、これは枠とは別の要素なので、透過版には含めない
  （隅飾りの先端が縁近くまで伸びるのは、飾りの一部として残る）。

## 透過版（派生）

- ファイル: frame-aged-v2-alpha.png（1280×1920 RGBA）。再生成は tools/extract_frame_v2.py。
- 作り方: 局所的な紙の明るさとの差で暗さを抜き、枠のある範囲（ゾーン）に限定し、
  小さな染みの粒を落とし、浮いた染みは実測した矩形で除去した。
- 左上の隅は原画では鉄板に隠れて見えないため、右上の隅を左右反転して補っている（枠は左右対称の設計）。
  鉄板の画素・断片は残していない。
- 紋章シールドと名前の文字は、枠ではないので透過させている。
- 派生の判定: 原本（aged v2 の枠）の判定を引き継ぐ。忠実さはモカが検品済み
  （白地・暗地に合成して四隅と全ての罫の連続を確認）。
